# OpenAI Setup Guide for mySmartly

## How OpenAI is Used in mySmartly

### 1. **Chatbot (AI Business Advisor)** ✅ Uses OpenAI
- **Purpose**: Explains and answers questions about recommendations
- **Model**: `gpt-4o-mini` (cost-effective, already configured)
- **Location**: `app/api/chat/route.ts`
- **What it does**: 
  - Takes user questions about recommendations
  - Uses OpenAI to explain why recommendations were made
  - Provides implementation guidance
  - Only reasons over provided recommendation context (doesn't make up data)

### 2. **Recommendations (Decision Feed)** ❌ Does NOT use OpenAI
- **Purpose**: Generates business recommendations
- **How it works**: Rule-based logic that analyzes connected data
- **Location**: `lib/recommendation-engine.ts`
- **What it does**:
  - Analyzes connected data sources (Google Analytics, Instagram Ads, etc.)
  - Uses predefined rules and patterns to generate recommendations
  - Based on user goals and data metrics
  - **No OpenAI needed** - it's pure data analysis logic

## Setup Instructions

### Step 1: Get OpenAI API Key

1. Go to [OpenAI Platform](https://platform.openai.com/)
2. Sign up or log in
3. Navigate to **API Keys** section
4. Click **"Create new secret key"**
5. Copy the key (you won't see it again!)

### Step 2: Add to Environment Variables

Add to your `.env.local` file:

```bash
OPENAI_API_KEY=sk-your-api-key-here
```

**Important**: 
- Never commit this to Git (it's already in `.gitignore`)
- Add it to your hosting platform's environment variables for production

### Step 3: Restart Your Development Server

```bash
# Stop the server (Ctrl+C)
# Then restart
npm run dev
```

## Current Model Configuration

The chatbot is currently configured to use:
- **Model**: `gpt-4o-mini`
- **Temperature**: 0.7 (balanced creativity)
- **Max Tokens**: 500 (concise responses)

### To Change the Model

Edit `app/api/chat/route.ts` line 97:

```typescript
model: 'gpt-4o-mini', // Change to 'gpt-4', 'gpt-3.5-turbo', etc.
```

**Model Options**:
- `gpt-4o-mini` - Cost-effective, fast (current)
- `gpt-4o` - More capable, slightly more expensive
- `gpt-4` - Most capable, most expensive
- `gpt-3.5-turbo` - Cheapest, good for simple tasks

## Alternative: Using Claude (Anthropic)

If you prefer Claude instead of OpenAI:

1. Get API key from [Anthropic](https://console.anthropic.com/)
2. Add to `.env.local`:
   ```bash
   ANTHROPIC_API_KEY=your-claude-api-key
   ```
3. The system will automatically use Claude if `OPENAI_API_KEY` is not set

## Troubleshooting

### "AI assistant is not configured"
- Check that `OPENAI_API_KEY` is set in `.env.local`
- Restart your development server after adding the key
- Verify the key is correct (starts with `sk-`)

### "Invalid API key"
- Regenerate your API key from OpenAI dashboard
- Make sure there are no extra spaces in the environment variable
- Check that you're using the correct key format

### "API rate limit exceeded"
- You've hit OpenAI's rate limits
- Wait a few minutes and try again
- Consider upgrading your OpenAI plan if this happens frequently

### Recommendations Not Showing
- **This is NOT related to OpenAI**
- Recommendations are generated by the recommendation engine (rule-based)
- Check that:
  1. Data sources are connected
  2. User has completed onboarding
  3. Recommendation generation API is being called
